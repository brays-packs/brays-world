# A Vanilla+ Experience

Welcome to Bray's official resource pack, **Bray's World!** This is a Vanilla+ pack that aims to maintain the base feel of the game while providing some 'extras' to spice things up and add some exciting, new variety.

-------------------

-------------------

-------------------


## Pack Features

### Custom Models
Many unique block and item models have been added to enhance the visuals of Minecraft. A few 2D blocks have been given 3D models to add further depth. Simple models like doors/trapdoors have also been updated to have increased depth while still staying simple and in the vanilla style

***Some blocks like walls, crops and potted plants even have random model variations**

## Mod Compatability
This pack has compatible functionality with many popular utility mods!

### Respackopts
Bray's World comes with the ability to use [Respackopts](https://modrinth.com/mod/respackopts) to customize your experience! You can turn off certain features of the pack you may not want and you can customize some settings, too

![Respackopts](https://cdn.modrinth.com/data/cached_images/72a42019e8df215ecbdda7d43abc46eae8a5ba2f.jpeg)

### Other Mods

[EMF](https://modrinth.com/mod/entity-model-features)/[ETF](https://modrinth.com/mod/entitytexturefeatures) - Entity model and texture variation

[Continuity](https://modrinth.com/mod/continuity) - Connected block textures

![Connected Textures Example1](https://cdn.modrinth.com/data/cached_images/a84189be0010a7b920155256ee63173e87648766.jpeg)
